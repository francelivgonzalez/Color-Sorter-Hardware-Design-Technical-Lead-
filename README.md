# Color-Sorter-Hardware-Design-Technical-Lead

A color-sorting automation system led through Texas State’s Robotics and Automation Society where I serve as a Technical Lead, using an Arduino UNO R3, TCS3200 color sensor, multi-servo actuation, stepper indexing, homing verification, and regulated power distribution.



## Overview

This project is an automated color-sorting system developed through the Robotics and Automation Society at Texas State University. As technical lead, I am responsible for helping drive the system design, troubleshooting, and roadmap execution for a hardware-focused sorting platform.

The system is being architected around an Arduino UNO R3, a TCS3200 color sensor, servo-based routing, stepper-controlled indexing, and homing verification to improve sort accuracy and repeatability.

## Objective

The goal of this project was to:

* design an automated color-sorting system
* classify objects based on sensed color data
* route parts into designated bins with controlled actuation
* improve alignment and repeatability through homing verification
* develop a structured hardware and controls roadmap

## Project Role

I am serving as Technical Lead for this project, supporting:

* system design and development
* troubleshooting and subsystem validation
* roadmap execution
* hardware integration planning

## System Architecture

* Arduino UNO R3
* TCS3200 color sensor
* multi-servo actuation
* PWM drivers
* stepper motors and motor drivers for indexing
* homing sensor for alignment verification
* DC-DC converter for regulated power distribution

## Skills Demonstrated

* embedded systems design
* hardware integration
* actuator control
* system troubleshooting
* roadmap planning
* technical documentation

## System Workflow

1. An object is positioned within the sensing area.
2. The TCS3200 sensor identifies the object's color.
3. The control system determines the proper destination bin.
4. Stepper-driven indexing and homing verification align the system.
5. Servo actuation routes the object with controlled motion.
